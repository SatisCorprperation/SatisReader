# Contributing guidelines

Please follow these guidelines when contributing to this repository.

## Code style
When writing new functions or files please note the following.
- All code must be PHP or HTML or CSS or JS.
- All comments must be discriptive.

## Pushing and changing code.
- Commit messages can be simple.
- Allways make a fork and push changes to your fork.
- Use the following command to commit: `git commit -s -m "Message 1(title)" -m "Message 2(Commit body)" -m "Trailer(E.G if coauthored by ai add here)"`
- If any issues or bugs occur in the `main` branch while testing please make a bug report issue.

## General rules.
- We aim to follow [ROADMAP.md](ROADMAP.md) for new features. Though fixes and other general changes are accepted as well.
- Follow the [Code Of Conduct](CODE_OF_CONDUCT.md)
